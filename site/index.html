Keep the speech. Drop the rest.

AeroSieve cuts raw recordings into 3–30 second clips, measures each one for noise, clipping, tones and silence, and writes the keepers as WebDataset shards. Every clip it throws away comes with a reason.

FLEURS is read speech recorded on volunteers' own devices, so some untouched clips really are noisy: most of what Hindi, Tamil and Bengali lose is source audio already under the 10 dB floor. LibriSpeech, recorded for audiobooks, keeps every clean clip.

How close is the noise estimate?

Median WADA-SNR reading against the noise level actually injected. Hover a point for the spread.

White and pink noise read within about 1.3 dB of the truth from 0 to 20 dB. Babble, other people talking, reads up to 2.7 dB cleaner than it is, because it looks like speech. Above 20 dB the curves flatten at the recordings' own noise floor.

What it caught in AeroSieve itself

  1. Clipping hid behind loudness leveling

    A loud, clipped file was turned down 3 dB before scoring, so its flat tops sat at 0.7 and passed as clean. Clipping is now measured against the source's own full scale.

  2. Speech was cut at every word gap

    A 100 ms pause ended a clip, so natural speech broke into fragments under 3 s and was dropped: 23 of 73 clean English recordings produced nothing.

From recording to shard

Four stages. One pass.

Cheap checks run before expensive ones, and each stage is its own crate you can use alone.

  1. Decode

    Symphonia reads the container, rubato resamples to 16 kHz, and loudness is leveled toward −20 dBFS.

    aerosieve-decode

  2. Segment

    A hysteresis state machine with Silero's defaults turns speech probability into 3–30 s clips.

    aerosieve-segment

  3. Score

    Four measurements per clip, then a FilterPolicy that names the first check a clip fails.

    aerosieve-acoustic

  4. Shard

    Kept clips go into WebDataset tar shards with a JSONL manifest and run totals.

    aerosieve-shard

# pip install ./bindings/python
import aerosieve

for clip in aerosieve.inspect("recording.wav")["clips"]:
    print(clip["start_s"], clip["duration_s"], clip["verdict"])

stats = aerosieve.curate(["a.wav", "b.mp3"], "data/run-1")
use aerosieve::{Pipeline, PipelineConfig};

let config = PipelineConfig::new("data/staging", "data/run-1");
let mut pipeline = Pipeline::new(config)?;
pipeline.process_file("recording.wav".as_ref(), Some("transcript"))?;

let stats = pipeline.finish()?;
println!("kept {:.1}%", stats.retention_rate() * 100.0);

What it doesn't do yet.

The thresholds have been checked on a few hours of audio, not against human ratings. FLEURS has no noise labels, so the tables above show what the filter does, not whether each rejection is right.

  • A single sustained instrument can pass as speech.
  • One transcript per file is copied to every clip. Transcripts aren't aligned to clips.
  • Speech is found by signal level unless you build with Silero VAD.
